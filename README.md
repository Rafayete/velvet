# Velvet

Reproductor de música para Android: tu música local con letras sincronizadas, estilos de reproductor, mezclas diarias y estadísticas.

## Descargar

**[⬇️ Descargar Velvet (APK)](../../releases/latest/download/Velvet.apk)**

## Cómo instalar

1. Abre el enlace de arriba desde tu teléfono Android y descarga `Velvet.apk`.
2. Ábrelo. Si Android pregunta, permite **instalar apps de esta fuente** (Chrome o tu navegador).
3. Si aparece un aviso de Play Protect, toca **Más detalles → Instalar de todas formas**. Sale porque la app no viene de Play Store.
4. Abre Velvet y dale permiso para leer tu música.

Para actualizar, descarga la versión nueva desde el mismo enlace e instálala encima: no se borra nada.

Requiere Android 7 o superior.
